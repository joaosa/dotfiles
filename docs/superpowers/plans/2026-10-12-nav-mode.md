# NAV Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A caps_lock tap outside a text field enters a Vimium-style NAV mode that drives the frontmost macOS app; inside a text field it keeps entering VimMode.spoon's NORMAL mode.

**Architecture:** Two Hammerspoon modules. `modules/vim.lua` owns the spoon, the f17 event tap that dispatches a caps tap to NORMAL or NAV, and every mode exit. `modules/nav.lua` absorbs today's `element-hints.lua` and adds an `hs.hotkey.modal` that synthesizes macOS-conventional keystrokes, a `NAV` badge, and its own click-to-exit tap. A tiny `lib/ax.lua` holds the shared focused-text-field predicate.

**Tech Stack:** Hammerspoon 1.1.1 Lua (`hs.hotkey.modal`, `hs.eventtap`, `hs.canvas`, `hs.axuielement`, `hs.application.watcher`), VimMode.spoon (pinned, unmodified), stylua 2.x via `nix run nixpkgs#stylua`.

**Spec:** `docs/superpowers/specs/2026-10-12-nav-mode-design.md`

## Global Constraints

- Hammerspoon config lives in `config/hammerspoon/`, symlinked live into `~/.hammerspoon`; `init.lua` calls `setup()` on each name in its `modules` list, in order.
- Format: `cd config/hammerspoon && nix run nixpkgs#stylua -- --check modules/nav.lua modules/vim.lua lib/ax.lua` must pass (4-space indent, 120 cols, `collapse_simple_statement = "FunctionOnly"`).
- Comments: 1 to 4 dense lines stating the constraint; no prose.
- VimMode.spoon and `config/karabiner/karabiner.json` are not modified. Karabiner sends f17 then escape on a lone caps tap.
- Only bound keys may be intercepted while NAV is active; the modal must never bind a key it does not act on.
- Reload after every edit with `perl -e 'alarm 5; exec @ARGV' hs -c 'hs.reload()'` (the auto-reloader misses heredoc rewrites) and confirm a clean load with
  `hs -c 'return tostring(hs.console.getConsole())' | grep -E "^$(date +%Y-%m-%d) $(date +%H)" | grep -i -E "error|Done" | tail -3`
  (last line must be `-- Done.` with no `error` line after the newest `Loading Spoon: VimMode`).
- Other sessions commit to `main` concurrently: run `git log -1 --oneline` before each commit, commit only the files named in the task, never `--amend`. Commit subjects only, no body, no co-author line.
- `hs -c` runs Lua inside the live Hammerspoon state, so `require("modules.nav")` returns the module table `init.lua` loaded; use it as the test harness.

## Review Focus

- Caps tap while hint labels are up: `nav.enter()` must cancel hints first so two consuming taps never coexist (test in Task 3).
- `enter()` twice then `exit()` once: must end inactive with the modal and click tap stopped exactly once (test in Task 3).
- `exit()` when already inactive: must be a silent no-op, since the app watcher and dispatch call it unconditionally (test in Task 3).
- A chord such as cmd+k pressed in NAV must reach the app: the modal binds exact modifier sets, verified by inspecting the modal's bound hotkeys (test in Task 4).
- Pending `g` must not survive an exit: `exit()` calls `clearPendingG()` (Task 3 Step 2) and the Finder check in Task 6 presses `g`, caps, caps, `g` and expects no jump.

- [ ] **Step 2: Add the modal, badge and click tap**

Insert into `config/hammerspoon/modules/nav.lua` after the `hintsActive` function and before `setup`:
```lua
-----------------------------------------------
-- NAV modal
-----------------------------------------------

local ax = require("lib.ax")

local BADGE = { w = 125, h = 25 }

-- hs.hotkey.modal intercepts only the keys bound below; everything else reaches the app.
-- Module-level so the modal, badge and click tap are not garbage collected.
local nav = {
    active = false,
    modal = hs.hotkey.modal.new(),
    badge = nil,
    clickTap = nil,
    pendingG = false,
    pendingGTimer = nil,
}

local function clearPendingG()
    nav.pendingG = false
    if nav.pendingGTimer then
        nav.pendingGTimer:stop()
        nav.pendingGTimer = nil
    end
end

local function badge()
    if nav.badge then
        return nav.badge
    end
    nav.badge = hs.canvas.new({ x = 0, y = 0, w = BADGE.w, h = BADGE.h })
    nav.badge:appendElements({
        type = "rectangle",
        action = "fill",
        roundedRectRadii = { xRadius = 2, yRadius = 2 },
        fillColor = { red = 76 / 255, green = 175 / 255, blue = 80 / 255, alpha = 0.95 },
        strokeColor = { white = 1.0 },
        strokeWidth = 3.0,
        withShadow = true,
    }, {
        type = "text",
        text = hs.styledtext.new("NAV", { font = { name = "Courier New", size = 14 }, color = { white = 1.0 } }),
        frame = { x = "5%", y = "10%", h = "100%", w = "95%" },
    })
    nav.badge:level("overlay")
    return nav.badge
end

local function showBadge()
    local frame = hs.screen.mainScreen():frame()
    badge():topLeft({ x = frame.x + (frame.w - BADGE.w) / 2, y = frame.y + frame.h - BADGE.h * 1.5 }):show()
end

local function exit()
    if not nav.active then
        return
    end
    nav.active = false
    clearPendingG()
    nav.modal:exit()
    if nav.clickTap then
        nav.clickTap:stop()
        nav.clickTap = nil
    end
    if nav.badge then
        nav.badge:hide()
    end
end

local function enter()
    if nav.active then
        return
    end
    cancelHints()
    nav.active = true
    nav.modal:enter()
    -- Clicking means mouse navigation; leave NAV and let the click through.
    nav.clickTap = hs.eventtap.new({ hs.eventtap.event.types.leftMouseDown }, function()
        exit()
        return false
    end)
    nav.clickTap:start()
    showBadge()
end

local function toggle()
    if nav.active then
        exit()
    else
        enter()
    end
end

local function isActive() return nav.active end

local function stroke(mods, key) hs.eventtap.keyStroke(mods, key, 0) end

-- Wraps a NAV action: if a text field has quietly taken focus (the spoon's observer misses this in
-- Electron apps) leave NAV and re-post the key so the app receives it; otherwise run the action.
local function action(mods, key, fn)
    return function()
        if ax.focusedTextField() then
            exit()
            stroke(mods, key)
            return
        end
        if key ~= "g" then
            clearPendingG()
        end
        fn()
    end
end

local function bindRepeat(mods, key, fn)
    local wrapped = action(mods, key, fn)
    nav.modal:bind(mods, key, wrapped, nil, wrapped)
end

local function bind(mods, key, fn) nav.modal:bind(mods, key, action(mods, key, fn)) end

-- Scrolling via arrow and page keys so it doubles as list navigation in Finder, Mail and Slack.
bindRepeat({}, "j", function() stroke({}, "down") end)
bindRepeat({}, "k", function() stroke({}, "up") end)
bindRepeat({}, "h", function() stroke({}, "left") end)
bindRepeat({}, "l", function() stroke({}, "right") end)
bindRepeat({}, "d", function() stroke({}, "pagedown") end)
bindRepeat({}, "u", function() stroke({}, "pageup") end)
-- Exit keys bypass the self-check so they never re-post into a field; escape is re-sent so the app
-- sees it too, matching the caps path where Karabiner's escape passes through.
nav.modal:bind({}, "i", exit)
nav.modal:bind({}, "escape", function()
    exit()
    stroke({}, "escape")
end)
```

Extend the return table:

```lua
    cancelHints = cancelHints,
    hintsActive = hintsActive,
    enter = enter,
    exit = exit,
    toggle = toggle,
    isActive = isActive,
}
```

Replace the comment and the `if key == f17 then ... end` block inside the key tap with:
```lua
    -- Karabiner sends f17 then escape on a lone caps_lock tap; the tap sees both in order before any app.
    -- f17 is always consumed. In a disabled app or while the spoon is already in normal/visual mode the
    -- escape passes through untouched. In a text field: enter NORMAL and swallow the escape (Slack closes
    -- a thread on escape). Anywhere else: toggle NAV and let the escape through so one tap still dismisses.
    local swallowEscape = false
    local f17, escape = hs.keycodes.map.f17, hs.keycodes.map.escape
    keyTap = hs.eventtap.new({ hs.eventtap.event.types.keyDown }, function(event)
        local key = event:getKeyCode()
        if key == f17 then
            swallowEscape = false
            if vim.enabled and vim:isMode("insert") then
                if ax.focusedTextField() then
                    nav.exit()
                    vim:enter()
                    swallowEscape = true
                else
                    nav.toggle()
                end
            end
            return true
        end
        local swallow = swallowEscape and key == escape
        swallowEscape = false
        return swallow
    end)
    keyTap:start()
```
Replace the app watcher comment and body with:
```lua
    -- The spoon only leaves normal mode on a focus change inside the app, and that observer fails for
    -- Electron apps, so a stray mode would follow an app switch. Both exits are no-ops when inactive.
    appWatcher = hs.application.watcher.new(function(_, event)
        if event == hs.application.watcher.activated then
            vim:exit()
            nav.exit()
        end
    end)
    appWatcher:start()
```
